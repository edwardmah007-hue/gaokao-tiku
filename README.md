# 物化生题库

面向广东新高考（物理 / 化学 / 生物）的个人题库，纯静态网页，部署在 GitHub Pages。

## 功能

- **录题**：科目、来源类别、年份、试卷名称、题号、分值、题型、难度、考点、题干、答案、解析、笔记；支持拍照上传题目图片（自动压缩）。连续录同一份卷子时自动沿用来源并把题号 +1。
- **来源可追溯**：试卷名称必填，每道题有「来源已核实」标记，未核实的题会醒目标出。
- **搜索与筛选**：全文搜索；按科目、来源、年份、难度、状态、考点、核实情况筛选。
- **试卷视图**：按年份和试卷归档，按题号排列，错题标红。
- **错题复习**：标记做错并选择错因后，按 1 → 2 → 4 → 7 → 15 → 30 天的间隔安排复习，全部答对后视为掌握。
- **统计**：薄弱考点（错题数 / 已做题数）、错因分布、各科题量、来源和难度分布。
- **公式**：题干、答案、解析里可写 LaTeX（`$...$` 或 `$$...$$`），由 KaTeX 渲染。
- **备份**：数据保存在浏览器的 IndexedDB，可导出和导入 JSON 备份；导入时按题目 ID 合并，较新的版本优先。

## 数据说明

所有数据只保存在当前设备的浏览器里，不会上传到服务器。换设备或清除浏览器数据前，请先在「数据」页导出备份。

## 本地运行

```bash
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。
